## Praca w GitHubie

1. Otwórz [Issues oznaczone `io`](https://github.com/Zasoby-Nieludzkie/Gra_Glowna/issues?q=label%3Aio) i wybierz zadanie.
2. W [Project #2](https://github.com/orgs/Zasoby-Nieludzkie/projects/2) znajdziesz statusy, terminy i pola godzin.
3. Po wykonaniu zadania odznacz gotowe punkty, dodaj rezultat lub link w Issue i wpisz faktyczny czas.
4. Po ukończeniu całego zadania zamknij Issue.
